One word — the word my ex would use to describe me. Exactly one word, nothing else.

## Entry

`Forgettable`

## How it works

`main.ts` writes the single word directly to `/output/entry.txt` with mode `0644`.
It first validates the entry is exactly one alphabetic word (no spaces, no
punctuation, no trailing newline), then reads the file back and asserts the
content is byte-identical and the mode is `0644` before exiting.

## Why this word

Five candidates were duelled (funniest + best gate fit + freshest angle):
Forgettable, Expensive, Exhausting, Temporary, Overdrafted. `Forgettable`
won: the ex's verdict is erasure itself — the sting is that there was nothing
worth remembering, and the laugh lands in the self-own.
